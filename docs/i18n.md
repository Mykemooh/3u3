# English and Spanish

Every person picks **EN | ES** (toggle in the app header, on sign-in and booking,
or in My Account → Settings). The choice is saved on their account (`users.locale`)
and in a cookie, so it follows them across devices, and every text and email
the system sends them goes out in that language. An owner can also set a
client's language on the client's profile in Admin.

## What's translated
- Cleaner app (`/crew`), including the how-to articles
- Client account (`/account`), booking (`/book`), new-client quote form (`/new`)
- Sign-in, forgot password, set password, two-step sign-in
- System emails and texts to clients and cleaners (reminders, confirmations, invoices, estimates, on-the-way, password and invites)

Still English: the owner workspace (`/admin`), the platform console, the marketing
sites, owner-facing emails, and anything a person typed (owner texts, Tex replies, notes).

## How it works
- `lib/i18n/index.ts`: locales, `defineMessages`, `format`, `translator`
- `lib/i18n/server.ts`: `getLocale()` (cookie, then saved choice, then browser, then English), `getT(book)`, `localeForUser(id)`
- `components/i18n/LocaleProvider.tsx`: `useT(book)`, `useLocale()` for client components
- `components/i18n/LanguageToggle.tsx` + `POST /api/locale`: the switch
- `lib/i18n/rich.tsx`: sentences with bold words or links inside
- `lib/i18n/messages/*.ts`: the words, one file per area, English and Spanish side by side

The type system requires every Spanish block to have exactly the English keys, so a
missing translation fails `npx tsc`.

## Reviewing or changing Spanish
Open the area's file in `lib/i18n/messages/` (crew, account, book, auth, common, forms,
notify, shell) and edit the `es` block. Clients are addressed as *usted*; the cleaner app uses *tú*.
Words worth a native speaker's check: "Recámaras" (bedrooms), "Plantas" (stories),
SMS wording length in `notify.ts`.

## Adding a screen
1. Add keys to the area's message file (or a new one) in both `en` and `es`.
2. Server component: `const t = await getT(book)`. Client component: `const t = useT(book)`.
3. Make sure the page sits under a `LocaleProvider` (AppShell and `components/AuthLocaleFrame.tsx` already do this).
4. Dates: pass the locale to `formatDateLabel`, `formatSlotLabel`, `formatSlot`, `formatClock`, or use `intlLocale(locale)`.
